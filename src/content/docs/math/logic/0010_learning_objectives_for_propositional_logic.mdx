## 命題論理のゴールを定める
　命題論理のゴールは、単に「かつ・または・ならば・否定を使って式を変形できるようになること」ではありません。

　命題論理のゴールは、**主張が持つ情報の構造を理解し、ある主張から別の主張が論理的に導けるかどうかを、自分で判断できるようになること**です。
集合論に進むために命題論理のすべてを極める必要はありません。どこまで理解すればよいか、到達目標を明確にしてみましょう。

### 目的：何のために命題論理を学ぶのか
 　命題論理で学ぶのは、**主張と主張がどのような論理的関係にあるのかを扱うこと**です。主張の内容を個別に調べることだけではありません。例えば、
 <Statements>
 - 主張$P$：$n$は4の倍数である。
 - 主張$Q$：$n$は偶数である。
 </Statements>
 という主張$P,Q$があるとします。この2つの主張から、次の主張が成り立ちます。
 $$
 P -> Q
 $$
 
 文章で記述すれば、「$n$が4の倍数ならば、$n$は偶数である。」という主張です。

 　この例えを使うと、主張$P$と$Q$は、前提条件として主張$P$があり、この下で結論として主張$Q$が得られるという論理関係があります。矢印$->$を使って、$P$と$Q$は論理的関係があると表現しているわけです。

### 役割：主張を組み立て、情報を扱う
　命題論理の役割は、大きく3つに分けられます。
<Card title="1.主張を組み立てる">
否定・連言・選言・含意などを使って、複雑な主張を構成する。
</Card>
<Card title="2.主張の関係を調べる">
同値か、矛盾するか、一方から他方が導けるかを調べる。
</Card>
<Card title="3.推論の正しさを判定する">
前提が正しいとき、結論も必ず正しくなるかを調べる。
</Card>
この3つが分かれば、論理記号や推論規則を単なる暗記項目ではなく、主張を扱うための道具として捉えられるようになります。

### 具体的に何を理解すればよいか
　次の5項目を命題論理の到達目標にするのがよいと考えます。
<TermList>
    <Term title="命題とは何かを説明できる">
        命題を、真か偽かが定まる主張として理解する。命題変数 P、Q は主張の内容を表す記号として扱う。
    </Term>
    <Term title="論理結合子の役割を説明できる">
        $not P$、$P and Q$、$P or Q$、$P -> Q$ が、それぞれどのような主張を作るのか説明できる。
    </Term>
    <Term title="含意と情報の関係を理解する">
        $P -> Q$ は、$P$ が真で $Q$ が偽になる場合を排除する主張である。$P$ が $Q$ より情報量が多いという見方も、この関係を理解する手がかりとして使える。
    </Term>
    <Term title="論理的に導けることを判断できる">
        前提から結論が必ず導けるか、反例となる真偽の組み合わせがあるかを調べられる。妥当な推論と妥当でない推論を区別する。 
    </Term>
    <Term title="同値・推論規則の意味を理解する"> 
        二つの式が常に同じ真偽になることと、ある前提から結論を導けることを区別する。連言除去・条件法証明・背理法などが何を可能にするか説明できる。
    </Term>
</TermList>

　理解できたか判断する基準は、記号を見て答えられることだけではありません。なぜその概念が必要なのか、何を判断できるようにするのかを自分の言葉で説明できることです。なお、条件法証明や背理法の形式的な証明を自在に扱うことまで、次に進むための必須条件にする必要はありません。まずは、その役割と基本的な仕組みが分かれば十分です。

### 一つの例で、ゴールに到達したか確認する
　次の推論を考えてください。
- 前提１：$P -> Q$
- 前提２：$P$
- 結論：$Q$

　これは妥当な推論です。なぜなら、$P$ が真であるのに $Q$ が偽ならば、前提１の$P -> Q$ が偽になってしまうからです。

　ここで大切なのは、単に「これは三段論法の一種だから正しい」と覚えることではありません。
- 目的： 結論が前提から必然的に導かれるかを調べる。
- 役割： 前提と結論の論理的なつながりを保証する。
- 構造： $P -> Q$ と $P$ が成り立つなら、$Q$ も成り立つ。
- 定義との関係： 含意の真偽条件に照らすと、結論が偽になる可能性が排除される。

このように説明できれば、命題論理を「推論規則の暗記」ではなく「主張の構造の理解」として学べています。
